# AI Business Intelligence Assistant — Architecture

## Overview
This application is a sales analytics dashboard built using Python, Streamlit, Pandas, and SQLite. It cleans sales data, calculates revenue, and answers supported business questions.

## Architecture Flow

Sales CSV
↓
Load and validate data using Pandas
↓
Clean invalid and incomplete records
↓
Calculate revenue
Revenue = Quantity × Unit Price − Discount Amount
↓
Store cleaned data in SQLite
↓
Process business questions using predefined rules and keywords
↓
Display answers and supporting data in the Streamlit dashboard

## Main Components

- app.py: Main application, data processing, question answering, and dashboard.
- ai_bi_assistant_sales_data - GET.csv: Input sales dataset.
- sales.db: SQLite database generated by the application.
- test_app.py: Automated tests.
- requirements.txt: Required Python packages.
- README.md: Setup and execution instructions.

## Known Limitation

The current question-answering system uses predefined rules and keywords. It does not connect to a large language model and only supports the question patterns implemented in the application.
