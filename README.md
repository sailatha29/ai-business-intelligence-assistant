# AI Business Intelligence Assistant

## Project Overview
The AI Business Intelligence Assistant is a Python-based sales analytics dashboard that helps users explore sales data by asking business questions in plain English.

## Features
- Displays total revenue, transaction count, and number of products.
- Identifies the product with the highest revenue.
- Shows monthly revenue trends.
- Compares revenue across regions.
- Calculates revenue changes between two months.
- Displays supporting data and charts.
- Stores cleaned sales data in a SQLite database.
- Includes automated tests for key question-answering functions.

## Technologies Used
- Python
- Streamlit
- Pandas
- SQLite
- Pytest

## Revenue Calculation
Revenue = Quantity × Unit Price − Discount Amount

The application excludes invalid, incomplete, returned, or non-completed transactions from its analysis.

## How to Run the Project

1. Install Python.
2. Open a terminal in the project folder.
3. Install the required packages:

   `python -m pip install -r requirements.txt`

4. Start the dashboard:

   `python -m streamlit run app.py`

5. Open the local URL displayed in the terminal.

## Run Automated Tests

Execute:

`python -m pytest test_app.py -v`

The current test suite contains seven tests, all of which passed during the latest test run.

## Project Files
- `app.py` — Main dashboard application.
- `test_app.py` — Automated tests.
- `requirements.txt` — Required Python packages.
- `ai_bi_assistant_sales_data - GET.csv` — Sales dataset.
- `sales.db` — SQLite database generated by the application.

## Current Limitations
The question-answering feature currently uses predefined rules and keywords. It does not yet use a large language model to understand arbitrary questions.
